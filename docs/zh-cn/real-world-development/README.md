通过真实场景、完整应用和共享待办列表，探索 GitHub Copilot 在软件开发生命周期中的应用。你将通过迭代来规划更改、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为桌游众筹提供服务，并以开发者为主题。团队的待办事项已作为 GitHub 议题创建，供你开始处理。其中既有筛选和分页等功能开发，也有无障碍访问和编码规范等质量改进。

## 选择工作环境

无论你在哪里工作，都能使用 GitHub Copilot。请选择适合你的开发环境。每个练习都会从自己的设置步骤开始，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright MCP、Agent Merge，以及实用的斜杠命令。

### [GitHub Copilot app][app]

运行并行代理会话、切换会话模式、协作使用画布，并在桌面 app 中管理 GitHub 议题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 议题分配给异步代理，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。通过 Copilot Chat 代理模式、MCP 服务器和自定义代理开展工作，无需离开编辑器。
