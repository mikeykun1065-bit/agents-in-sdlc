Copilot cloud agent の演習を始める前に、必要な環境を準備します。[codespaces][codespaces] を作成し、指示ファイルの編集や cloud agent が作成した変更のレビューに使います。

## ラボ用リポジトリを設定する

コードを作成するためのリポジトリを用意します。[テンプレート][template-repository]から新しいリポジトリを作成してください。新しいリポジトリにはラボに必要なファイルが含まれ、演習を通して使用します。

1. 新しいブラウザー ウィンドウで [Tailspin Toys テンプレート][tailspin-template]に移動します。
2. ラボ リポジトリのページで **Use this template** ボタンを選択し、**Create a new repository** を選択して自分用のコピーを作成します。

    ![Use this template button](../../../_images/ex0-use-template.png)

3. GitHub または Microsoft が主催するイベントでワークショップを受講する場合は、メンターの指示に従ってください。それ以外の場合は、GitHub Copilot を利用できる組織に新しいリポジトリを作成できます。

    ![Input the repository template settings](../../../_images/ex0-repository-settings.png)

4. 作成したリポジトリのパス (**organization-or-user-name/repository-name**) をメモしてください。ラボの後半で使用します。

## Codespace を作成する

続いて、ラボの演習に使う Codespace を作成します。

[GitHub Codespaces][codespaces] は、ブラウザーで直接コードの作成、実行、デバッグができるクラウド開発環境です。複数のプログラミング言語、拡張機能、ツールをサポートする IDE を利用できます。

1. 作成したリポジトリに移動します。
2. 緑色の **Code** ボタンを選択します。

    ![Select the Code button](../../../_images/ex0-code-button.png)

3. **Codespaces** タブを選択し、**+** ボタンを選んで新しい Codespace を作成します。

    ![Create a new codespace](../../../_images/ex0-create-codespace.png)

Codespace の作成には数分かかりますが、必要なサービスを手動でインストールするよりも早く完了します。その間に GitHub Copilot のほかの機能を確認してみましょう。

> [!CAUTION]
> 後の演習で Codespace に戻ります。今はブラウザーのタブを閉じずに開いたままにしてください。

> [!NOTE]
> このワークショップは Codespace またはローカルの [dev container][dev-containers] で動作するように構成されています。どちらも必要な前提条件が整った環境を提供します。ローカルで実行する場合は、クローンしたリポジトリを VS Code で開き、表示されたら **Reopen in Container** を選択してください。Codespace と同じ dev container が構築されます。

[codespaces]: https://github.com/features/codespaces
[dev-containers]: https://code.visualstudio.com/docs/devcontainers/containers

## まとめ

ラボ リポジトリのコピーを作成し、Copilot cloud agent と作業するための Codespace の作成を開始できました。
